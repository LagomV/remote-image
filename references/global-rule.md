## AI 生图渠道

- 需要 AI 生成/编辑像素图片时使用 `remote-image` Skill，先问“这次用中转站，还是默认生图？”已选渠道的同一任务不重复问；用户明确要求某渠道时直接遵循。
- MATLAB/Python/Origin 数据图表、Mermaid、SVG/代码绘图、图片裁剪缩放、文档排版，以及仅讨论图片或生成无 AI 插图的文档/试卷，不触发。科研示意图方式不明时先问代码绘制还是 AI 生图。
- 首次安装/初始化后主动询问 URL 和 API key，再问仅本对话使用、只记住地址、或本机加密保存；保存前必须明确取得选择。用户可另选以后 AI 生图默认用中转站；未选则仍询问渠道。
- 只有明确同意长期保存后才跨聊天读取本 Skill 的本地配置；不从历史聊天、主模型配置或旧环境变量找 key。更换 URL 必须提供新 key；停止使用立即停止当前对话中转站调用。
- key 不回显、不写入规则/Skill/提示词/日志/命令行/长期环境变量。保存使用 Windows 用户级加密，不能随 GitHub 仓库分发。具体行为和维护命令读取：`__SKILL_PATH__`。
