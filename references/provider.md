# 接口兼容与故障处理

面向支持 `/v1/models`、`/v1/images/generations`、`/v1/images/edits` 的 OpenAI 风格图片中转站。不是所有声称兼容的服务都支持同一模型、流式响应、尺寸或质量参数。

- URL 使用服务商给出的 API 根地址，不填网页控制台、单个生图端点；末尾可带 `/v1`，代理自带路径前缀会保留。远程地址必须 HTTPS；HTTP 只允许本机测试。
- 默认模型沿用原 Skill 的 `gpt-image-2`，可在配置时指定其他图片模型。这是配置默认值，不是服务商可用性保证。
- 优先流式响应，兼容 `data[].b64_json`、`data[].url` 和流式完成事件。忽略部分图片事件，不把预览当最终结果。
- `/models` 404/405：可能仅未实现列表；不要反复探测。401/403：停止并检查地址、密钥和权限。模型在列表中也不保证实际生图成功。
- 400：检查模型、尺寸、质量、参数，不原样重试。503/524 或连接中断：最多一次重试，超时后服务端可能仍在计算，有重复计费可能。
- 成功但没有最终图片：报告接口格式不兼容，不打印完整响应；不自动切换其他渠道。
- 调用者须打开图片验证内容；本地模拟测试只能验证传输流程，不能证明真实中转站可用或成图正确。
- 不自动迁移旧版明文环境变量，也不改变 Codex 自身的模型、代理或 hooks 配置。
