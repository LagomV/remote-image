# 中转站生图 · remote-image

给 Codex 使用的 Windows 生图 Skill。AI 生图时选择中转站或默认渠道；MATLAB、Python、Origin 数据绘图不会因此被询问。

只负责连接和配置，不改变论文、文案、教学或文档的工作流程。

## 最简单的安装方式

准备：Windows、Codex、本机 Python 3.10 或更新版本。核心功能不需要额外 Python 包。

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**（下载压缩包）。
2. 解压，在 Codex 中打开包含本 README 和 SKILL.md 的文件夹。
3. 把下面一句话发给 Codex：

   > 请安装并初始化这个文件夹里的 remote-image Skill。运行 scripts/setup.py install，把规则部署到全局；安装后主动问我中转站 URL 和 API key，再让我选择是否保存配置。不要读取我其他服务的密钥。

4. 按提示提供 API 地址和密钥。密钥也可以在自己可见的 PowerShell 窗口隐藏输入，避免发到聊天。
5. 选择保存方式：仅本次对话使用、只记住地址，或者本机加密保存地址和密钥。
6. 选择以后每次 AI 生图询问渠道，还是默认使用中转站。默认是询问。
7. 新开 Codex 聊天。若还未识别 Skill，重启 Codex 后再试。

下载文件本身不会执行安装，也不会自动弹出配置。由上面的安装请求启动引导。

## 不经过聊天填写密钥

在解压文件夹空白处打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

这是仅对本次进程生效的执行策略参数，不会修改系统的长期策略。安装后自动进入本机配置向导，密钥隐藏输入。选择“不保存”后，生图时还需提供临时密钥。

如受组织策略限制，可以让 Codex 运行 Python 安装脚本，不需要更改组织策略。

## 哪些请求会询问

| 请求 | 行为 |
|---|---|
| “生成一张水彩插画”“用 AI 换掉背景” | 询问中转站或默认生图 |
| “用中转站生成一张插画” | 已明确渠道，直接检查中转站配置 |
| “用 MATLAB 绘制实验曲线”“Python 散点图” | 不询问，走代码绘图 |
| “制作一份试卷”“排版这份论文” | 不因可能涉及图片而询问 |
| “解释这张图”“把图片裁成正方形” | 不询问 |
| “画一张科研示意图” | 先问代码绘制还是 AI 生图 |

AI 生图渠道的选择在同一任务中沿用。你可以随时说“改用默认生图”。已选择以后默认中转站时，跨聊天沿用本机配置，但数据绘图仍不触发。

## 配置保存在哪里

- 新电脑默认安装到 `~/.agents/skills/remote-image`。已有旧版 `~/.codex/skills/remote-image` 时沿用旧位置，避免两份并存。
- 全局只添加一段带 `BEGIN_REMOTE_IMAGE` / `END_REMOTE_IMAGE` 标记的说明，保留其他内容。不添加 hooks，不改变 Codex 主模型、代理或其他 Skill。
- 默认配置在 `~/.codex/remote-image/settings.json`。设置了 `CODEX_HOME` 时，配置、全局规则和备份使用该目录。
- URL、模型和默认渠道是普通配置；密钥使用 Windows DPAPI 当前用户加密，URL 与密钥绑定。
- 不保存到仓库，不设置长期环境变量，不在“查看配置”时显示密钥。加密配置不能复制到另一台电脑使用，且不能防止同一 Windows 账号下的恶意程序。
- 密钥若发到聊天，聊天和工具调用记录可能保留它；本机加密不能消除这些记录。

## 常用说法

- “初始化中转站生图”
- “查看中转站配置”（只显示地址和是否存了密钥）
- “更换中转站”（必须为新地址提供新密钥）
- “以后 AI 生图默认使用中转站”
- “以后默认使用内置生图”
- “忘记保存的密钥”
- “删除全部中转站配置”
- “卸载这个 Skill，保留配置”或“卸载并删除配置”

更新时，从新版本文件夹再次请求安装。安装前自动备份被替换文件；已被用户修改的安装文件会停止覆盖并提示处理。

旧版全局规则如规定“只能在本次聊天使用”，需要你同意迁移后，才使用 `scripts/setup.py install --migrate-legacy`。卸载时恢复旧规则这一节，不把整个全局文件恢复成旧版。

## 已知边界

- 目前面向 Windows；其他系统不提供本机密钥加密保存保证。
- 需要中转站实现相应图片接口；URL 应为 HTTPS API 根地址，默认模型 `gpt-image-2`，可更改。不是所有中转站都兼容。
- 安装不发起付费生图。实际调用、上传编辑图片、重试可能涉及服务商费用，遵循你对任务的授权。
- 使用说明能引导 Codex 的行为，但不是系统级硬拦截；是否加载新规则需在新聊天实际检查。

脚本详情见 [配置与调用](references/usage.md)，接口差异见 [兼容说明](references/provider.md)。

开发验证：`python -m unittest discover -s tests -v`。测试使用虚拟密钥和本机模拟接口，不调用真实中转站。
